# Student Management SQL

A basic MySQL project for practicing SQL database and table management using a Student Management dataset.

## Concepts Covered

- Creating a database using `CREATE DATABASE`
- Selecting a database using `USE`
- Creating tables using `CREATE TABLE`
- Inserting records using `INSERT INTO`
- Retrieving data using `SELECT`
- Updating records using `UPDATE`
- Deleting records using `DELETE`
- Filtering data using `WHERE`
- Using logical operators `AND`, `OR`, and `NOT`
- Pattern matching using `LIKE`
- Sorting data using `ORDER BY ASC` and `ORDER BY DESC`
- Removing duplicate values using `DISTINCT`

## Database Structure

**Database:** `College`

**Table:** `Student`

| Column | Data Type | Description |
|---|---|---|
| Student_ID | INT | Unique student ID |
| Student_Name | VARCHAR(100) | Student name |
| Age | INT | Student age |
| Department | VARCHAR(100) | Student department |
| Grade | VARCHAR(10) | Student grade |

## Queries Practiced

The project includes queries for:

- Student records management
- Age-based filtering
- Department filtering
- Grade filtering
- Name and department pattern matching
- Sorting students by age and ID
- Finding distinct ages
